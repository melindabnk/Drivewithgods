# Drive With Gods (AGOS)

### Description
Drive With Gods est un prototype de jeu de course mythologique développé sous Unity.
Le joueur incarne un pilote lié à une divinité, chaque dieu apportant un style de conduite et des mécaniques spécifiques.

Le projet explore la fusion entre gameplay arcade et univers mythologique.

---

### Technologies
- Unity
- C#
- ShaderLab (expérimentation visuelle)
- ScriptableObjects
- Git

---

### Fonctionnalités actuelles
- Système de véhicule avec physique personnalisée
- Déplacements sur piste avec gestion des virages
- Début de système de pouvoirs divins
- Gestion simple des états de jeu
- Organisation du projet en systèmes indépendants

---

### Objectifs pédagogiques
- Structurer un projet Unity complexe
- Développer des systèmes modulaires
- Apprendre à organiser un projet proprement
- Découper un gameplay en briques techniques
- Gérer les itérations et le debug
